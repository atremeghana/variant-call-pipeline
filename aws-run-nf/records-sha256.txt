They differ because: the two runs used the same pinned tool versions and the same smoke dataset,
but ran through different orchestration layers - Part A executed the pipeline's own bash script
directly inside one container, while Part B had Nextflow invoke each GATK/samtools stage as a
separate task. The most likely source of the difference is GATK HaplotypeCaller's documented
floating-point non-determinism in its multi-threaded PairHMM implementation (the same effect
observed between the Nextflow and Snakemake runs on Explorer in weeks 4 and 5), which can
produce small genotype-likelihood differences between runs even with identical inputs and tool
versions.
